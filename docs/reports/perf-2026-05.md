## Appendix — Methodology Notes

- **PostHog:** All numbers come from HogQL queries against project `326191` for the date range `2026-05-01 00:00:00 UTC` to `2026-06-01 00:00:00 UTC` via the `/api/projects/326191/query/` endpoint. Personal API key sourced from `apps/admin-portal/.env`.
- **Website-only filter:** `not startsWith(properties.$pathname, '/portal') and not startsWith(properties.$pathname, '/studio')` — strips Designer Portal app and Sanity Studio events that share the same PostHog project.
- **Internal-traffic identification:** distinct_ids resolving to `kody.kochaver@gmail.com`, `kody.kochaver+hihi@gmail.com`, `test@kochaver.com`, `client@middlewest.studio`, and the iOS UUID `e01db20f-…`. All May website distinct_ids fall into this set.
- **Supabase waitlist:** `GET https://api.patina.cloud/rest/v1/waitlist?select=*&order=created_at.desc` with the service-role key from `PatinaWebsite/.env.local`. Total table size: 2 rows.
- **Sanity:** GROQ query `*[_type == "journalPost"] | order(publishedAt desc)` against project `kv3qrinl`, dataset `production`. Returned 3 documents, all April-published, all `tier: null` and `status: null`.
- **AI citation and SEO deltas:** Sourced from `docs/reports/ai-citation-2026-06.md` (run 2026-06-02) and `docs/reports/seo-audit-2026-06.md` (run 2026-06-01).
- **Surface assumption:** the `e01db20f-…` distinct_id appears as both uppercase and lowercase. PostHog treats them as separate distinct_ids; iOS sends uppercase UUID strings and the web SDK lowercases them. Treated as the same identity for this report.
- **April Supabase discrepancy:** noted in funnel section. Not resolved by this run; recommended action is a `git log -- app/api/waitlist supabase/migrations` review and a one-shot Supabase audit query.
