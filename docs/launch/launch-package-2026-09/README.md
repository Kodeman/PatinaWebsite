## Files and portability

Open `launch-book.html` or `creative/index.html` in a browser. HTML, images, fonts, and PDFs work from the extracted package. Markdown and CSV remain editable in ordinary text and spreadsheet applications. The `references/` folder contains dated snapshots and original provenance context. Historical wording in those snapshots does not supersede the latest messaging system or the exact public caption: **Illustrative imagery — awaiting partner photography.**

The package contains no customer export, account credentials, or private client details. Reference documents may mention repository source paths; those are provenance pointers, not required files for viewing the book or artwork.

See [quality-checks.md](quality-checks.md) for the actual render, link, and content checks completed at handoff. `build-package.py` regenerates the readable document HTML; `render-package.mjs` regenerates PDFs and presentation checks with the repository’s Playwright installation.
