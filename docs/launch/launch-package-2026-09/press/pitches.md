## Dispatch discipline and outreach log

Kody owns the suggested press workflow and maintains the log. Leah joins design-focused interviews and validates studio/project details. Send individually through the listed editorial route. Use the actual recipient’s name only when confirmed on the publication’s current site; a team greeting is preferable to a guessed name.

Use these log fields:

| Field | Purpose |
| --- | --- |
| Outlet, market, official route, last checked | Know where the pitch went and when the route was verified |
| Pitch version and actual angle | Identify the story offered, not just the campaign name |
| Human owner and spokesperson | Keep replies and interview requests from going unanswered |
| Local relevance / reporting evidence | Record the reason this outlet is a fit; link any real regional participant’s permission |
| Planned send, actual send, follow-up due, actual follow-up | Separate intention from completed action |
| Status | Prepared / sent / replied / interview requested / declined / no reply / published |
| Response and next action | Capture deadlines, requests, and who will act |
| Assets offered, credit, permission, exclusivity terms | Track what may be reused and whether another project submission conflicts |
| Published URL and publication date | Record actual coverage, not a promised placement |
| Tagged link, observed referral traffic, observed signups | Review outcomes with the launch dashboard; note missing consent or stripped parameters |
| Preference / do-not-contact | Respect the recipient’s instructions |

Do not log guessed personal details, add journalists to a marketing list, or record an introduction as a partnership. Do not trade advertising purchases for an assumed editorial result. A reply, an interview, and a published story are separate outcomes.
